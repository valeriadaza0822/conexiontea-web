# ConexiónTEA 2.0 — página web

Proyecto HTML + CSS + JavaScript puro inspirado en el prototipo 


## Archivos

- `index.html` — página principal (landing).
- `login.html` — inicio de sesión.
- `registro.html` — crear cuenta.
- `dashboard.html` — panel del paciente.
- `styles.css` — diseño, colores, responsive y temas.
- `script.js` — código compartido (accesibilidad, temas).
- `dashboard.js` — navegación del dashboard y texto a voz.
- `auth.js` — registro e inicio de sesión (demo con localStorage).

## Nota

Es una versión frontend/demo. El inicio de sesión, almacenamiento de usuarios, base de datos y API todavía no están conectados a un backend.
